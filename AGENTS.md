# Agent notes

## Language

Speak to the user in Japanese.

Write English in anything this repository keeps: code, tests, comments, README, commit messages, and GitHub pull request titles and bodies. Follow the wording already in the README and the commit history.

## Keep workplace material out

inkshade is a general-purpose tool. Do not add workplace material to the repository:

- internal product names, team names, ticket IDs
- customer data, shop domains, production hosts, or log excerpts from work
- business rules or workflows from a job

Use generic placeholders in tests and docs (`example.com`, obviously fake values). Do not commit planning notes that contain the items above.

Token shapes this tool already detects, such as `ghp_` or `AIza`, are part of the tool. Those stay.
